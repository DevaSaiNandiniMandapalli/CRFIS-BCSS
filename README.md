# CRFIS — Cyber Risk Financial Impact System

**BCSSL COMMAND CENTER — From Information to Intelligence**

CRFIS is a cyber-risk financial intelligence platform that transforms cybersecurity risk data into decision-ready financial insights for security and executive teams.

## Core Capabilities

- Executive financial risk overview
- Risk Register with severity, probability, exposure, ownership and status
- Asset Register with business value and criticality
- Remediation tracking with cost, expected reduction, priority and deadlines
- Scenario analysis for potential cyber events
- Cyber insurance coverage and exposure-gap analysis
- Audit programs and findings
- Executive Reports and analytics
- AI Analyst powered by local Ollama
- Deterministic intelligence for fast executive questions
- Multi-currency financial reporting without mixing EUR, USD or INR

## Technology

- React + TypeScript + Vite
- Fastify + TypeScript
- Prisma ORM
- PostgreSQL
- Ollama
- Qwen 2.5 Coder 3B
- Node.js
